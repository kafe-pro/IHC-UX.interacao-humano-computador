# Sobre o projeto
## Objetivo
  Prototipação de interface de aplicativo e integração dos conceitos de Design Centrado no Usuário e Acessibilidade.
## A ideia
  Aplicativo para entregadores no modelo de negócio "freelance". Acessibilidade volta para deficientes visuais (Empresa) e deficientes auditivos (Entregadores).
## Softwares utilizados
  - Penpot
